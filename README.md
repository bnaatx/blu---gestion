# Blu Gestión

App de Blu Accesories para registrar pedidos, ventas, inventario, costos, materia prima, la remodelación de productos y la parrilla de contenido.

- Se instala en el iPhone desde Safari con "Agregar a pantalla de inicio".
- Los datos se guardan en Supabase (tabla `registros`), protegidos con inicio de sesión. Este repositorio solo tiene el código de la app.
- `config.js` tiene la URL del proyecto y la clave pública de Supabase.
